# Build and update — "GCP" sheet visuals

The 8 SVGs in this folder are generated by `gen.py`, one per tool topic (plus one for the OAuth setup)
of the sheet `GCP` in the Xmind map `UZWWd58n`. Do not hand-edit the `.svg` files: edit `gen.py`
and regenerate.

Palette and primitives live in `../../lib/flatvec.py`, shared with every other image set in this repo.
The one builder specific to this set, `f_flow` (four boxes with arrows plus a gotcha line), is in `gen.py`.

## Regenerate

```
python3 gen.py
```

Writes all `*.svg` next to the script and rewrites `INDEX.md` (Xmind node id -> file).

## Change one image

1. Find its `add(<anchor>, "<name>", f_flow(...))` line in `gen.py`; `<anchor>` is the Xmind topic id.
2. Edit it and run `python3 gen.py`.
3. Push (Git data API, one commit; no clone is required, see the repo README).
4. Re-attach in Xmind with `xmind_set_topic_image` (fileId `UZWWd58n`, topicId = the anchor,
   imageUrl = the raw URL with `?v=N`, N bumped when the content changes but the name does not).
