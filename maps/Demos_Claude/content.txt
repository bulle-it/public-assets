=== web | Claude Web
# Claude Web : je discute ::cover
> Porte d'entrée par défaut : claude.ai dans le navigateur, sur le même compte que Desktop et mobile. On ne la quitte que lorsque Claude doit agir sur mes vrais fichiers ou mes outils.
## Ce que c'est ::section
- claude.ai dans le navigateur, rien à installer ::card:globe
- Claude ne voit que ce que j'écris ou joins : pas mes fichiers, pas mes mails ::card:eye
- Pour une info récente, il lance une recherche web et cite ses sources ::card:search
- Installable comme application depuis Chrome : identique au web, sans accès au poste ::card:device
## Régler Claude Web en français ::section
- Langue : Paramètres → Général → Langue → Français ::card:gear
- Confidentialité : désactiver « Contribuez à améliorer nos modèles IA » ::card:shield
- Recherche web : à activer, sinon Claude répond de mémoire à sa date de coupure ::card:search
- Projets : instructions permanentes et fichiers de référence qui regroupent les conversations ::card:folder

=== code | Claude Code
# Claude Code : je fais construire ::cover
> Un agent qui travaille dans un dossier de projet : il lit, écrit et lance des programmes sur mon poste. Toutes les démos de cet onglet viennent de nos projets réels.
## Ce que c'est ::section
- Un agent sur un dossier de projet : il lit, écrit, lance des commandes et des programmes ::card:term
- Le savoir-faire reste dans des fichiers : CLAUDE.md pour les règles, memory pour la mémoire, skills pour les commandes ::card:book
- Quatre portes : onglet Code de Desktop, extension VS Code, terminal, claude.ai/code dans le cloud ::card:grid
## Régler Claude Code ::section
- Modes de permission : Manuel, Accepter les modifications, Plan, Auto ::card:hand
- Règles permanentes : un fichier CLAUDE.md à la racine du projet ::card:doc
- Outils autorisés : fichier .claude/settings.json, liste blanche de commandes ::card:shield
- Skills : un fichier texte par commande dans .claude/commands ::card:list
## Démos bureautique ::section
### La procuration : remplie, imprimée, archivée {label: vidéo à héberger} ::demo:office:/procuration
> Vidéo complète de 13'24'' et pilote de 30'' dans Training_git/Outputs ; données personnelles floutées par /remake.
- Ce que voit l'apprenant : je décris le résultat, Claude retrouve mes documents dans Drive, prépare le formulaire, imprime et archive
- Sous le capot : outils PDF, commande d'impression, Drive, connecteur Xmind pour expliquer la démarche
- Pourquoi Claude Code : imprimer, remplir le PDF officiel et classer demandent d'agir sur mon poste
- Limite : je relis le document imprimé avant de signer
### /fly : le vol direct le moins cher avec parking navette {label: lien privé à publier} ::demo:office:/fly
> Rapport interactif « Fly Paris–Oran » produit par le skill : lien privé à publier, ou à remplacer par une exécution de démonstration.
- Ce que voit l'apprenant : un tableau avec un prix cliquable par cellule, un rapport interactif et un mail récapitulatif
- Sous le capot : navigateur automatisé, aéroports résolus selon le lieu de départ, quatre moteurs de vol, plusieurs parkings
- Pourquoi Claude Code : piloter un navigateur sur plusieurs sites de prix et refaire la même recherche à chaque voyage
- Limite : un site refondu peut casser la lecture ; un échec reste un lien, jamais un faux « pas de vol »
### Bureautique en série : /email, /transcript, /sick-leave {label: démo en direct} ::demo:office:/email
- /email : sept comptes, pièce jointe retrouvée dans le Drive, jamais d'envoi sans go explicite
- /transcript : audio sensible transcrit en local, synthèse rédigée sous forme de courrier
- /sick-leave : justificatifs d'un dossier triés, renommés, contrôlés puis transmis
- Pourquoi Claude Code : tâches répétées, plusieurs comptes et sites, garde-fous écrits une fois dans le skill
## Démos comptabilité ::section
### Documents du comptable : lire, signer, archiver, répondre {label: réalisée} ::demo:accounting:/signature

- Pourquoi Claude Code : chaque document demande sa signature à un endroit différent, vérifié page par page

### Justificatifs manquants rattachés à la banque {label: réalisée} ::demo:accounting:/justificatifs

## Démos audio et vidéo ::section
### /remake : le montage vidéo automatique {label: vidéo à héberger} ::demo:training:/remake
