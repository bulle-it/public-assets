# Originality options — how this set is built

- `gen.py` draws every SVG with the shared palette and primitives in `../../lib/flatvec.py` and writes
  `INDEX.md` (node id to file). Run `python3 gen.py` from this folder.
- One image per top-level branch of the Xmind sheet "Originality: free options". The node ids in
  `gen.py` belong to file `mKRiB2a3`, sheet `3997fca9-9e51-4607-9caf-250ff1cd76f6`.
- Attach with `xmind_set_topic_image` using the raw URLs; if a file changes but keeps its name,
  re-attach with `?v=N`.
- Public repo: wording stays generic (no personal names, no project data).
